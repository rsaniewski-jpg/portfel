# Portfel Kart

Karty lojalnościowe w telefonie. Dodajesz kartę (sklep + numer spod kodu kreskowego), a przy kasie pokazujesz kod do zeskanowania.

**Otwórz:** https://rsaniewski-jpg.github.io/portfel/

- Logo sklepu pobiera się samo (popularne sklepy rozpoznaje po nazwie)
- Kody EAN-13, EAN-8, Code 128, Code 39 i QR
- Działa bez internetu po pierwszym otwarciu
- Karty są zapisane tylko w telefonie (nic nie trafia do tego repozytorium). W sekcji „Kopia zapasowa” można zapisać i wczytać plik z kartami.

Dodaj do ekranu głównego: iPhone – Safari → Udostępnij → „Do ekranu początkowego”; Android – Chrome → ⋮ → „Dodaj do ekranu głównego”.
